# Анализ состояния компьютера

Скрипт собирает данные о машине, на которой его запустили, оценивает каждый
показатель (info / warn / critical) и показывает только те уровни, которые
выбрал пользователь. Заготовленных данных нет: каждый запуск - свежий анализ.

## Запуск

Нужен Python 3.8+, зависимости не нужны. Работает на Linux и Windows
(на macOS часть проверок пропускается).

```
python3 filter_events.py                 # меню (Enter - critical, q - выход)
python3 filter_events.py critical        # только критичное
python3 filter_events.py warn critical   # несколько уровней
python3 filter_events.py --file events.json   # готовый файл вместо анализа
```

В меню после результата: Enter - назад к выбору уровней, `r` - заново снять
данные с системы, `q` - выход.

## Что проверяется

| Проверка | warn | critical |
|----------|------|----------|
| Заполнение каждого диска | от 80% | от 90% |
| Оперативная память | от 80% | от 90% |
| Swap | от 50% | от 80% |
| Нагрузка cpu (load average / число ядер) | от 1.0 | от 2.0 |
| Упавшие systemd-службы (Linux) | - | каждая служба |
| Ошибки в системном журнале за час (Linux, journalctl) | - | от 20 |
| Доступ в интернет | нет соединения | - |
| Время работы системы | - | - |

У каждого события warn и critical есть строка «возможно: ...» с вероятной
причиной и подсказкой, что проверить. У info её нет.

Если проверка недоступна (нет прав, нет systemd, другая ОС), она пропускается,
остальные работают.

## Пример

```
$ python3 filter_events.py critical

анализ системы: 9 событий, показываю critical

  1. critical диск /usr/lib/wsl/drivers занят на 96% (918.7 ГБ из 952.9 ГБ)
     возможно: разросшиеся логи, кэш, старые бэкапы или загрузки; скоро может не хватить места для записи
  2. critical служба не запустилась: apache2.service
     возможно: ошибка в конфиге, занятый порт или нет зависимости; причину покажет systemctl status apache2.service
  3. critical ошибок в системном журнале за час: 52
     возможно: сбои служб, драйверов или диска; подробности: journalctl -p err --since -1h

критичных 3
скрыто 6
```

`скрыто` - сколько событий других уровней не показано (`all` покажет всё).

`events.json` оставлен как пример готового набора событий для `--file`
(формат: список `{"event": "...", "level": "info|warn|critical", "hint": "необязательно"}`).
